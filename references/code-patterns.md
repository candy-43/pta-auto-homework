# PTA 高频题型 · Python 3 代码模式库

全部模式在 2026-09 "第二次上机任务" 13 题中实测 AC。核心原则：**输出格式以样例逐字符反推，不凭题面猜。**

## 1. 定宽整数输出

```python
# 左补空格（右对齐），宽度 3："3*5= 15"
a, b = int(input()), int(input())
print('{}*{}={:3}'.format(a, b, a * b))

# 右补空格（左对齐），宽度 3，行尾带空格："3  *5  =15 "
print('{:<3}*{:<3}={:<3}'.format(a, b, a * b))

# 等价写法
s.rjust(3)      # 左补空格
s.ljust(3)      # 右补空格
f'{a * b:>3}'   # 右对齐
f'{a * b:<3}'   # 左对齐
```

## 2. 前导 0

```python
# 个位数加前导 0：9 -> 09；两位数不变：12 -> 12
n = int(input())
print(str(n).zfill(2))
# 等价：print('%02d' % n)
```

## 3. 浮点数精度

```python
# 保留 2 位（四舍五入）：3.1415 -> 3.14
x = float(input())
print('%.2f' % x)

# 一行输出两个精度："3.14, 3.142"（逗号后有空格）
print('%.2f, %.3f' % (x, x))
# 等价：print(f'{x:.2f}, {x:.3f}')
```

## 4. 分隔符与 sep

```python
# 默认 sep=' '："A B C D E"
print('A', 'B', 'C', 'D', 'E')
# 逗号分隔："A,B,C,D,E"
print('A', 'B', 'C', 'D', 'E', sep=',')
# 连字符分隔："A-B-C-D-E"
print('A', 'B', 'C', 'D', 'E', sep='-')

# 三行输入各一个字符串，两种分隔各输出一行
a, b, c = input(), input(), input()
print(a, b, c)           # "2023 09 10"
print(a, b, c, sep='-')  # "2023-09-10"
```

## 5. 一行多值输入

```python
# 空格分割："3 5"
a, b = map(int, input().split())

# 逗号分割："3, 5"（int() 自动忽略前后空格，无需 strip）
a, b = map(int, input().split(','))
print(a + b)
```

## 6. 字符串拼接 / str.format()

```python
# 中文拼接："您好，孙同学！"
x = input()
print('您好，' + x + '同学！')

# str.format()："今天是2023年03月09日，天气晴。"（月/日按原样输入，天然带前导 0）
y, m, d, w = input(), input(), input(), input()
print('今天是{}年{}月{}日，天气{}。'.format(y, m, d, w))
```

## 易错点备忘

1. **按字符串读 vs 按数值读**：输入 `03` 若要原样输出前导 0，用 `input()` 存字符串；要参与运算才 `int()`。
2. **`%.3f` 是四舍五入**：3.1415 → 3.142（不是截断）。
3. **行尾空格**：`'{:<3}'.format(15)` 输出 `15 `（带尾空格），与样例一致就照抄；PTA 判题默认容忍行尾空白，但精确复刻最稳。
4. **别用 input() 提示语**：`input('请输入：')` 的提示串会被算进输出，WA 重灾区。
5. **多行输入就是多个 input()**，每行一个；不要用 sys.stdin 在单题里折腾。
